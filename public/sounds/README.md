# Real sound recordings (optional)

The app generates every sound in code. To use a real recording instead, add an
`.mp3` here with one of these names and list the name (without `.mp3`) in
`manifest.json`, e.g. `["airhorn", "letsgo"]`:

airhorn, siren, applause, ooh, letsgo, boo, fail, music

Only use sounds you're allowed to: free-license sites such as Pixabay (Content
License) or Freesound filtered to CC0.
